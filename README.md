# Fish Catching game

This is a minigame combining all of the comonents, in which you can walk around and catch fish. If the fish are caught the type of fish that you have caught will print to the console, and if you fail to catch a fish it will print fail to the console.
The fish will swim around in the pool, looking semi realistic to how real fish swim, and after the the number of fish in the pond is below 2, a random amount of wish will spawn back into the pool, allowing you to catch more. The rarest fish to catch is an orca with a 1/50 chance to spawn in.
